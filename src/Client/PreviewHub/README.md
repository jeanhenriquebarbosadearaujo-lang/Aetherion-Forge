# PreviewHub

HUB de preview mobile-first (preto / cinza). Arte 100% programada: Frames, UIGradient, UIStroke, UICorner, ícones vetoriais por slot. Sem Toolbox.

- Entrada: `Hub.client.lua` (LocalScript em StarterPlayerScripts)
- Cria `ScreenGui PreviewHub` no PlayerGui em runtime
- 8 slots `#1`–`#8` (placeholders)
- Layout em Scale + UIAspectRatioConstraint; centro da tela livre
