# Relatório de bugs — Gacha (2026-09-09)

Varredura no código de Testes (PreviewHub + GachaClient + GachaService). Sem CFrame de mapa; o preview 3D usa `PivotTo` no dummy R6.

## Corrigidos

1. **Auto-Roll + cooldown** — o loop chamava `RollOnce` mais rápido que o cooldown do servidor (0.55s), gerando `err=cooldown` em silêncio. Intervalo agora **0.90s**, com wait cancelável.
2. **Flag `rolling` presa** — fechar o menu no meio do `InvokeServer` deixava `rolling=true` e travava o próximo giro. `closeMenu` zera a flag e incrementa `autoGen`.
3. **Auto-Roll não desligava de verdade** — o loop antigo podia chamar `stopAuto` no fim e competir com um novo start. Token `autoGen` invalida loops velhos.
4. **Leak de RenderStepped** — rotação do dummy agora desconecta em `clearWorld` / `closeMenu`.
5. **UI sobreposta** — menu refeito com `UIListLayout` + padding Scale (folga entre carta, textos e botões). Girar e Auto-Roll lado a lado com padding **0.06**, cada um com ~42% da largura. Margens do painel ~5.5%.
6. **Estado do menu** — última carta (`lastCardId`) reabre o preview R6 ao abrir de novo; Auto-Roll sempre off ao fechar.

## Sem erro residual no fluxo

- Sorteio continua só no servidor.
- Sem uso de CFrame em peças do mapa (nada para quebrar física).
- Console esperado: `[Aetherion] GachaService ready` e `[Aetherion] GachaClient ready`.
